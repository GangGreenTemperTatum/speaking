# Security Policy

This repository is a static portfolio site published through GitHub Pages. It serves content only and processes no user input server-side.

## Reporting a vulnerability

Please report security issues privately through GitHub's
[**Report a vulnerability**](https://github.com/GangGreenTemperTatum/speaking/security/advisories/new)
form rather than opening a public issue. Include the affected page or file, what you observed, and a way to reproduce it.

Secrets are scanned on every push and pull request (TruffleHog) and locally before every commit. If you believe a credential was committed, report it the same way and do not open a public issue.
